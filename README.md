# distilled-ppse-phishing
Code and data for the MSc thesis "Leveraging Distilled LLM Knowledge to Detect Persuasion Principles for Effective Spear-Phishing Detection" (Ben-Gurion University, 2026). 5,771 emails scored by Llama 3.1 70B for five persuasion principles, and ModernBERT models distilled from those scores.
